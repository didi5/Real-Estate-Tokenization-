# TokenImmo — Web3 Real Estate Product Prototype

> **Portfolio category:** FinTech & Web3 · Product & Academic Projects  
> **Status:** Academic frontend prototype

A responsive multi-page product prototype exploring how real estate owners and investors could interact with a Web3-based property investment platform.

The concept focuses on making real estate investment more accessible through Security Token Offerings (STOs), a simplified owner journey, an investor community, and an interactive payout calculator.

> The repository does not currently include a production backend, authentication, blockchain integration, token issuance, payment processing, or validated financial calculations.

## Product overview

TokenImmo explores a digital platform for two primary user groups:

- **Property owners**, who want to unlock liquidity without directly selling their assets.
- **Investors**, who want easier access to tokenized real estate opportunities and community benefits.

## Key features

- Multi-page website with consistent navigation
- Separate journeys for property owners and investors
- Owner-focused STO calculator prototype
- Explanatory onboarding journey
- Investor-community and loyalty concept
- Responsive navigation and mobile layout
- Lightweight implementation without a framework

## Technology stack

## Current limitations

- Payout parameters are not fully integrated or tested.
- No authentication, database, backend API, smart contracts, wallet, or token infrastructure is implemented.
- Community actions and contact functions are visual placeholders.
- The project is not financial, investment, legal, or real-estate advice.
